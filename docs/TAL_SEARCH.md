# إصلاح البحث عن ميخائيل تال وإضافة مبارياته

كشف فحص 27 نوفمبر 2026 أن النسخة الأساسية المنشورة تضم **57 مباراة** للاعب مسجّل باسم `Tal, Mihail`. إدخال `Mikhail Tal` لم يكن يعالج اختلاف التهجئة، وكان البحث العام يسمح أيضاً بأن تأتي كلمة من اسم الخصم أو البطولة. سجلات تال التاريخية لا تتضمن حقول `WhiteTitle` و`BlackTitle`، فيستبعدها مرشح GM الصريح.

يسجل [متحف FIDE الرسمي](https://museum.fide.com/champions/mikhail-tal) الاسم `Mikhail Tal`، بينما تستخدم سجلات [إيداع Figshare المرخّص](https://doi.org/10.6084/m9.figshare.4276523.v1) صيغة `Tal, Mihail`. أضيف سجل صيغ أسماء صريح في `studio/knowledge/player_names.py` يدعم الاسمين وترتيبهما العكسي والبحث العربي. يطابق الاسم داخل خانة لاعب واحدة، ولا يخلط تال بلاعبين مثل Tal Baron أو ببطولات تحمل اسمه. تظل أسماء المصدر ومعرفات المباريات وحقول الألقاب كما هي.

من الواجهة: **مركز المعرفة ← مباريات الأساتذة ← كل مباريات الأرشيف**، واختر كل المصادر أو Figshare. ابحث بـ`Mikhail Tal` أو `Mihail Tal` أو `ميخائيل تال`. تعرض نتيجة البحث الاسم الموحد، وتظهر بطاقة المباراة اسم PGN الأصلي. عند غياب النتائج تحت مرشح GM يظهر تفسير وزر للبحث في كل الأرشيف مع الحفاظ على بقية المرشحات.

## إضافة البيانات

تضم [إضافة تال](https://github.com/Ali133-7/chess-ai-coach/releases/tag/tal-games-2026-11-27) **1,999 مباراة** و**138,197 نقلة فردية**، بسنوات مسجلة من **1949 إلى 1992**. اختيرت من لقطة معاملات متسقة لقاعدة الاستيراد التاريخي، وأعيد فحص كل خط رئيسي ومعرفه ومصدره قبل التغليف. تحفظ الإضافة PGN الأصلي المنظّف، والترخيص CC BY 4.0، ونسبة العمل إلى Ana Schaigorodsky، وبصمة الأرشيف وترتيب السجل. لا تحتوي حسابات أو مفاتيح أو سجلاً شخصياً.

هذه سجلات تال المقبولة والمتاحة في لقطة المصدر حين التصدير، وليست ادعاء اكتمال كل مبارياته المنشورة عالمياً. أعداد `archives` في manifest تصف مرور المصدر الأصلي؛ عدد سجلات الإضافة الفعلي هو `stats.games`. تفاصيل اختيارها في `tal-selection.json`. تقييمات المحرك الغائبة تبقى غائبة؛ الشرح المحلي لحقائق الرقعة والتحليل الاختياري بـStockfish يعملان كالمعتاد.

## تثبيت الإضافة بأمان

حدّث كود/صورة التطبيق إلى `6f244d1` أو أحدث. نزّل `tal-supplement.sqlite3.gz` و`tal-supplement-manifest.json` من الإصدار نفسه إلى مجلد `tal-supplement`. استخدم أداة **دمج الإضافة مع الكتالوج الموجود**:

```bash
python scripts/apply_game_library_supplement.py \
  --archive ./tal-supplement/tal-supplement.sqlite3.gz \
  --manifest ./tal-supplement/tal-supplement-manifest.json \
  --destination ./studio-data/master-library.sqlite3
```

مع Compose والـvolume الافتراضي:

```bash
docker compose run --rm --no-deps \
  -v "$PWD/tal-supplement:/public:ro" studio \
  python scripts/apply_game_library_supplement.py \
  --archive /public/tal-supplement.sqlite3.gz \
  --manifest /public/tal-supplement-manifest.json \
  --destination /studio-data/master-library.sqlite3
```

تفحص الأداة البصمات والجداول والمصادر، وتبني نتيجة مرحلية تحافظ على كل معرف موجود، وتحتفظ بنسخة الكتالوج السابق قبل الاستبدال الذري. ترفض وجهة حسابات أو رابطاً رمزياً أو كتالوجاً قيد الكتابة، وتتحقق من عدم تغير القاعدة أثناء الدمج. تحتاج مساحة تجهيز ونسخة احتياطية إضافية؛ لا تشغّلها على قاعدة يبنيها مستورد نشط. البيانات الشخصية مستقلة عن هذه العملية. إعادة الإضافة لا تضاعف المباريات.

## الاختبارات

تشمل اختبارات الانحدار: تطابق صيغ الاسم وترتيبه والعربية؛ منع مطابقة خصم اسمه Mikhail مع لاعب آخر اسمه Tal؛ احترام السنة والمصدر ومرشح GM والصفحات؛ البحث في العينة القديمة؛ استبعاد قواعد الحسابات؛ وحفظ المعرفات وعدم التكرار عند تطبيق الإضافة مرتين. تستخدم اختبارات المتصفح مباراة فعلية من المصدر على أربعة أحجام شاشة، وتفحص عرض الاسم والترخيص والنقلات وزر تجاوز مرشح الألقاب. ## نتيجة النشر

نُشر الكود `6f244d1` بعد نجاح **325 اختبار Python و44 اختبار متصفح و15 مجموعة DOM**. أضيفت **1,942 مباراة جديدة** إلى النسخة الحية؛ كانت 57 من مباريات الإضافة موجودة مسبقاً. بلغ الكتالوج الموسع **1,053,543 مباراة**، والمجموع المعروض مع العينة القديمة **1,053,903** بعد استبعاد المعرفات المتكررة. أعاد الفحص الفعلي لصيغ الاسم الإنجليزية والعربية الأربع **1,999 نتيجة**، واستغرق كل طلب نحو **304–374ms** في عينة الفحص؛ هذه ليست ضمان سعة أو زمن استجابة ثابت.

حُفظ الكتالوج السابق قبل الاستبدال، ونجح فحص سلامة القواعد والمفاتيح الأجنبية وبقاء الحسابات والصفوف القديمة، مع استعادة المؤقتات وتشغيل الموقع وعامل التحليل والمزامنة بالإصدار نفسه. بقي Groq جاهزاً، ولم تُطبع مفاتيحه أو تدرج في الإضافة. أُخذت نسخة احتياطية خاصة مشفرة وجُرّبت استعادتها معزولة؛ تبقى خارج ملفات Git العامة.
