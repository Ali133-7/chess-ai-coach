# عرض اللاعبين وألوانهم

تستخدم قائمة المباريات الشخصية، وآخر المباريات في الرئيسية، ومكتبة المباريات التاريخية صفاً منفصلاً لكل لاعب: رمز قطعة بلونه، الاسم الأصلي كاملاً، واسم اللون مكتوباً. يعرض الصف نتيجة الطرف المسجلة: 1 أو 0 أو ½. لا تُستنتج نتيجة لمباراة مجهولة النتيجة. يظهر اللقب فقط إذا ورد في سجل المصدر؛ لا تُخترع ألقاب أو تصنيفات.

تظهر هوية اللاعب فوق الرقعة وتحتها في مراجعة المباريات الشخصية ودراسة المباريات التاريخية. عند تدوير الرقعة تنتقل هوية كل طرف إلى جانب قطعه. يبدأ الأرشيف التاريخي بالأبيض في الأسفل؛ تبدأ المراجعة الشخصية بلون حساب Chess.com المرتبط، أو بالأبيض إن لم يطابق الحساب أياً من الطرفين. لا يبدّل تغيير اللغة هوية اللاعبين أو ترتيبهم أو FEN.

تشير علامة «صاحب الدور / To move» إلى حقل الدور في FEN المعروض، بما فيه السيناريوهات، وتختفي عند آخر وضعية في تسلسل مباراة ذات نتيجة مكتملة. النتيجة الظاهرة تخص سجل المباراة بالكامل، وليست توقعاً للفوز في الوضعية المعروضة. علامة «أنت / You» تتطلب تطابق اسم اللاعب مع اسم حساب Chess.com المرتبط؛ لا يكفي أن تكون المباراة موجودة في أرشيف المستخدم.

المكوّن المشترك `studio/static/game_players.js` يعمل محلياً دون طلب API إضافي لكل نقلة. يحافظ على صفّي الرقعة عند التنقل لتجنب إعادة إنشائهما، ويزيل عرض اللاعبين عند الانتقال إلى دراسة افتتاحية. الأسماء تُعزل اتجاهياً باستخدام `bdi` وتُهرب قبل إدخالها في HTML. أسماء طويلة تلتف داخل البطاقة؛ حقول الألوان والحالة تترجم مباشرة إلى العربية والإنجليزية.

لا تحتاج هذه الإضافة إلى migration أو إعادة استيراد أو تعديل قاعدة البيانات أو مفاتيح الخدمات. يتم نشر ملفات الواجهة معاً من صورة إصدار واحدة، مع تغيير إصدارات روابط الملفات لمنع خلط النسخة القديمة والجديدة في ذاكرة المتصفح. حدّث الصفحة بعد النشر؛ ترقية أي خادم قائم تتبع خطوات النسخ والاستعادة والترويج في `docs/RELEASE_AUTOMATION.md`.

## التحقق

- `npm test`: يتضمن اختبار escaping للأسماء، عدم اختراع الألقاب، نتائج الطرفين، تطابق الحساب، ترتيب اللاعبين عند التدوير، الدور من FEN، نهاية التسلسل، تبديل اللغة، وعدم تراكم صفوف إضافية عند إعادة الرسم.
- `npx playwright test --grep "player names colours"`: رحلة حقيقية تبدأ بتسجيل الدخول في قاعدة مؤقتة، ثم قائمة ومراجعة شخصية، وتدوير ونقلات ولغة، ثم مباراة تال الحقيقية، مع فحص تطابق عرض صفوف اللاعبين والرقعة وعدم تجاوز عرض الشاشة. تعمل على 320 و390 و768 و1280 بكسلاً.
- اختبارات المتصفح الكاملة تبقى مسؤولة عن التحقق من التشغيل التلقائي والمصادر والترخيص والتدريبات وباقي المسارات.

على Windows يمكن تعيين `CHESS_E2E_PYTHON` إلى Python في البيئة الافتراضية و`CHESS_E2E_CHANNEL=msedge` لاستعمال Edge المثبت. على CI يُثبّت Chromium وفق ملف workflow الموجود. خادم المتصفح التجريبي يعزل بياناته في مجلد مؤقت ولا يفتح قواعد النشر.
