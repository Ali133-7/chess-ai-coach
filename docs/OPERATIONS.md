# التشغيل والنشر

## نسخة المستودع

بدأ المستودع من مطابقة الشيفرة المنشورة في 23 نوفمبر 2026، ثم أضيفت تحديثات مستقلة باختبارات وترحيلات. ملفات Docker وCompose تبني تشغيلاً كاملاً من المصدر ولا تعتمد على سلسلة صور التصحيحات السابقة. راجع [إصدار الاعتمادية](RELIABILITY_RELEASE.md) و[دليل النشر الآلي](RELEASE_AUTOMATION.md) للإضافات الحالية.

## الخادم الحالي

الرفع إلى GitHub لا يغيّر الخادم أو مفاتيحه أو قواعد بياناته. آخر ترقية متحققة في 24 نوفمبر 2026 شغلت `4451622` بصورة `technical-20261124-4451622`. لا تستبدل Compose الحالي بنسخة المستودع مباشرة، لاختلاف أسماء وحدات التخزين وإعدادات التشغيل. اختبر صورة معزولة وخذ نسخة متسقة، ثم حدّث **الموقع والعامل والمزامنة وكل عامل/مؤقت يكتب إلى البيانات نفسها معاً**. لا تستخدم checkout قديماً لإعادة البناء. إصدار الحسابات الجديد يضيف شرطاً للتراجع: لا تخدم حسابات MFA بصورة قديمة تتجاوز العامل الثاني.

مؤقت التمارين الموجود: `chess-coach-exercises-20261122.timer`. حاوية `daily-exercises` في compose بديل مستقل اختياري؛ لا تفعلها بجانب المؤقت على البيانات نفسها.

## البيانات العامة

`scripts/prepare_public_data.py` يفك قاعدة مباريات الأساتذة العامة بعد التحقق من البصمة. `scripts/bootstrap_knowledge.py` ينشئ الجداول ويستورد الافتتاحيات والألغاز والإحصاءات المحلية والمباريات والأمثلة المولدة باستيراد قابل لإعادة التنفيذ.

لا تنسخ `studio.sqlite3` أو `knowledge.sqlite3` الجاريتين من الخادم إلى Git؛ قاعدة المعرفة الجارية قد تتصل بسجل التدريب وملفات تخزين خاصة. الملف المضغوط المرفق هنا قاعدة عامة مستقلة لا تحتوي حسابات.

## الخدمات القديمة

للمحافظة على تطبيقات الأرشيف السابقة توجد خدمة `coach` وعامل `deep-worker` ضمن ملف التعريف `legacy`. جهّز `CHESS_USERNAME` و`CHESS_API_KEY` عشوائياً بطول 32 حرفاً على الأقل في `.env` قبل تفعيلها. التطبيق الحديث `studio` يستخدم حسابات المستخدمين الخاصة به.

```bash
docker compose --profile legacy up -d coach deep-worker
```

## النسخ الاحتياطية والمفاتيح

احتفظ بنسخ البيانات خارج Git واستخدم SQLite backup API للحصول على نسخة متسقة. يحتوي `studiodata` على حسابات وتقدم ومفاتيح خاصة. يحفظ أمر الإعداد المفاتيح بصلاحية `0600` ويستخدم إدخالاً مخفياً. لا تُرسل مخرجات المفاتيح إلى السجلات.

للاستضافة العامة، جهّز TLS عبر وكيل عكسي واضبط `STUDIO_BASE_URL` على الأصل الصحيح و`STUDIO_COOKIE_SECURE=true`. احتفظ بالخدمات الداخلية مرتبطة بالواجهة المحلية.
