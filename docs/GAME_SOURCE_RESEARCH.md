الهدف هو توسيع قاعدة الدراسة بمباريات فعلية وموثقة من فترات مختلفة. وجود PGN قابل للتنزيل أو ترخيص للكود في GitHub لا يكفي وحده لإسناد ترخيص جديد إلى تجميعة البيانات. راجعت المصدر الأصلي، ونطاق الترخيص، وإمكانية إعادة التوزيع، ونوع السجلات، وحجم الملفات، ثم جودة النقلات الفعلية. لم أرسل طلبات إلى أصحاب المواقع أو أنسخ محتوى يتطلب تجاوز منع وصول.

## التحقق من ملف Figshare الفعلي

- الإيداع مثبت إلى **v1**، والملف رقم **6971717**: `all.pgn.zip`.
- حجم ZIP: **870,891,090 بايت**. عضو PGN واحد اسمه `all.pgn` وحجمه المفكوك **3,076,796,490 بايت**؛ لا تُفك مسارات ZIP إلى نظام الملفات.
- MD5 المنشور: `90bed9e33640e7eab354a40dfd1eddb8`. استُخدم كفحص سلامة من الناشر، وليس كتوقيع أمني.
- SHA-256 المثبت بعد تنزيل الملف والتحقق منه: `86732c0a23421da5985f5ba40d9db9bf2be1f6e2456b88629c35740ae71be54d`.
- فُحص تدفق العضو كاملاً وCRC. المحتوى لا يجتاز UTF-8 الصارم، ويجتاز **Windows-1252**؛ استُخدم هذا الترميز دون استبدال صامت للحروف غير المفهومة.
- ظهر اختلاف تنسيق مؤثر: أسطر فارغة متعددة بين الرؤوس والنقلات، وأسطر فارغة داخل سجل النقلات نفسه. `python-chess` يعد السطر الفارغ نهاية مباراة. أُضيف قارئ يحدد حد السجل عند بداية رؤوس المباراة التالية خارج التعليقات، ويحافظ على حدود تعليقات الفاصلة المنقوطة. اختُبرت أيضاً رؤوس وهمية مكتوبة داخل تعليق متعدد الأسطر.
- مثال الفحص الحقيقي هو **Kasparov, Garry × Stoffers, Jeffrey، 14 مارس 2000**، مباراة عرض متزامن، وخطها المسجل **67 ply**. لا يعرضها النظام باعتبارها GM ضد GM، لأن الملف لا يذكر لقبي الطرفين. مصدر الـfixture وبصمته في `tests/fixtures/historical-first.source.json`.

لا يُستخدم الملف الثاني `all_with_filtered_anotations.zip` بوصفه PGN؛ يصفه الناشر بأنه بيانات مفلترة للتحليل بصيغة نصية. لم أستنتج منه مباريات كاملة أو أخلط أعداده مع عدد السجلات المقبولة من الملف الخام.

## سياسة الاستيراد وجودة البيانات

1. التحقق من بصمة المصدر وحجمه، وترخيصه المثبت.
2. التحقق من الأسماء، والسنة المعروفة، والنتيجة المتطابقة بين رأس PGN وجسمه، والبداية القياسية، وكل نقلة قانونية. تُستبعد نهايات السجل المقطوعة والنتائج المخالفة لوضعية نهائية.
3. تجاهل التعليقات البشرية والتفرعات، والاحتفاظ بالتقييم الرقمي المهيكل فقط إذا وُجد، مع التصريح بأن إعدادات محرك المصدر غير معروفة. لا يتم توليد تقييم وهمي لوضعية بلا تقييم.
4. منع تكرار الهوية نفسها اعتماداً على الاسمين والتاريخ والحدث والجولة وFEN البداية وتسلسل UCI. اختلاف صيغ الأسماء قد يبقي لقاءين متشابهين؛ لا تدّعي هذه الطريقة حل كل الأسماء المستعارة.
5. حفظ المصدر، وبصمة ZIP، واسم العضو، وسياسة الاختيار/الترميز، وترتيب السجل في التدفق المطبع. كل دفعة ومؤشر استئنافها يُحفظان في معاملة واحدة.
6. تبدأ دفعة قابلة للمراجعة، مع أولوية لبعض الكلاسيكيات، ثم يمكن استئناف بقية المصدر. `target-games` حد تشغيل للدفعة، وليس ادعاء اكتمال الأرشيف. حالة `paused` لا تعني `complete`.

لا يُستنتج لقب GM من الاسم أو Elo، ولا تُخلط تقييمات Lichess عبر الإنترنت مع تصنيف FIDE. الفلتر الافتراضي في الواجهة يعرض جميع سجلات الأرشيف المثبتة؛ فلتر GM يحتاج `WhiteTitle=GM` و`BlackTitle=GM` صراحة، لذلك لا يُخفي غياب اللقب في ملفات قديمة تلك الألعاب من العرض العام.

## الترخيص والدمج

مخطط المكتبة **v2** يضيف تعريف المصادر وسجل عمليات الدمج دون حذف السجلات القديمة. القارئ والمثبت يدعمان ملفات **v1** السابقة. ملف Figshare الأصلي يحتفظ بـ **CC BY 4.0** ونسبة العمل إلى Ana Schaigorodsky، وملفات بث Lichess تحت **CC BY-SA 4.0**. التجميعة المعدّلة المشتركة وشروح حقائق الرقعة التي يولدها التطبيق تُنشر تحت CC BY-SA 4.0؛ تصدير لعبة مفردة يحفظ ترخيص مصدرها ونسبته.

يُنشئ الدمج ملفاً جديداً. إذا كان الأرشيف نفسه مستورداً سابقاً بسياسة GM ثم بسياسة جميع الألقاب، تُحفظ سياستا الفحص في مصدرَي سجل منفصلين باستخدام جزء `#catalogue-scan=...` في معرف الأرشيف، وتبقى بصمة الملف الأصلي نفسها. لا يتغير معرف المباراة ولا ترتيب نقلاتها. عدادات كل عملية استيراد تُحفظ كما كانت في مصدرها؛ أعداد الألعاب النهائية محسوبة من الصفوف الفريدة، وسجل الدمج يبين التكرار بين الكتالوجات.

المراجع الشخصية والحسابات ومفاتيح الخدمات ليست مدخلات لهذه الأدوات. يتحقق المُصدّر من قائمة الجداول والأعمدة والمصادر المسموح بها، ويُثبت الملف العام ذرّياً باسم `master-library.sqlite3` فقط، مع الاحتفاظ بنسخة الكتالوج السابق عند الاستبدال.

## أوامر إعادة الإنتاج

داخل بيئة أدوات البيانات من جذر المستودع:

```bash
python -m pip install -r requirements-data.txt
python scripts/fetch_historical_archive.py --directory ./historical-data/archives
python scripts/import_historical_games.py --archive ./historical-data/archives/all.pgn.zip --database ./historical-data/historical.sqlite3 --inspect-only
python scripts/import_historical_games.py --archive ./historical-data/archives/all.pgn.zip --database ./historical-data/historical.sqlite3 --target-games 20000
```

لإعطاء أولوية للكلاسيكيات، باستخدام سياسة مستقلة في القاعدة نفسها:

```bash
python scripts/import_historical_games.py --archive ./historical-data/archives/all.pgn.zip --database ./historical-data/historical.sqlite3 --players Morphy,Anderssen,Philidor,Steinitz,Capablanca,Alekhine,Lasker --target-games 7000
```

إعادة الأمر تستأنف سياسته. لإكمال المرور غير المفلتر على الملف، أعد أمره **دون** `--target-games`؛ لا تغيّر أسماء المصدر أو الترميز لتجاوز اختلاف البصمة. الاستئناف يعيد فك ZIP والمرور على الرؤوس السابقة للوصول إلى مؤشره، وليس استئنافاً مباشراً عند بايت داخل ZIP.

ادمج كتالوجات عامة موثقة فقط، إلى وجهة جديدة:

```bash
python scripts/merge_game_libraries.py --input ./current-public-library.sqlite3 --input ./historical-data/historical.sqlite3 --output ./combined/master-library.sqlite3
python scripts/game_library_artifact.py verify --database ./combined/master-library.sqlite3
python scripts/game_library_artifact.py package --database ./combined/master-library.sqlite3 --output ./combined-release
```

أضف `--deep` إلى التحقق أو التغليف لإعادة فحص كل PGN مجدداً؛ النقلات تُفحص أصلاً عند إدخالها. اتبع [دليل تثبيت المكتبة](OPEN_GAME_LIBRARY.md) للتثبيت. لا تشغّل بناء الأرشيفات داخل عامل الويب أو على ملف المكتبة الحي. تتطلب الملفات الكبيرة مساحة ووقت معالجة؛ الأدوات تحفظ مساحة احتياطية وتتوقف عند بلوغها.

للمرور الكامل المتوازي يمكن تشغيل حتى أربعة عمال، مثلاً ثلاث عمليات بالأعلام `--partitions 3 --partition 0` ثم `1` ثم `2`، إلى القاعدة نفسها بعد تهيئتها. كل عامل يعيد قراءة التدفق، لكنه يحلل فقط السجلات التي يطابق ترتيبها قسمته؛ تحفظ السياسة ومؤشرها بصورة مستقلة. تُحسب الألعاب الفريدة من القاعدة، ولا تُجمع أعداد المرور المتكرر بوصفها ألعاباً إضافية. ضع سقف CPU/RAM خارجياً، وانتظر اكتمال جميع الأقسام قبل وصف المصدر بأنه مستورد كاملاً.

الأسماء محفوظة كما وردت، ولا تعني تسميات مثل NN توثيق هوية خصم مجهول. كما لا تعني تغطية مصدرين تغطية كل بطولة وكل سنة؛ تتحدد التغطية الفعلية بإحصاءات السجلات المقبولة، وتبقى بيانات الفترات والمصادر غير المتاحة خارج ادعاءات الإصدار.
