# واجهة إدارة المنصة

افتح «المزيد ← إدارة المنصة» بحساب المدير. تنقسم القائمة إلى المتابعة، والعملاء والإيرادات، والتسويق، والخدمات والتشغيل. يمكن البحث في أسماء الأقسام على الكمبيوتر؛ على الشاشات الأصغر تظهر قائمة أقسام قابلة للبحث بدلاً من شريط طويل من الأزرار. تظل الأقسام الأحد عشر ووظائفها متاحة بالعربية والإنجليزية.

تعرض النظرة العامة أرقام API الفعلية وحالات تحليل المباريات والتوليد اليومي. البيانات غير المتوفرة تظهر «—»؛ لا يُولّد منحنى مالي أو مؤشر نمو غير محسوب. توجد اختصارات للمستخدمين والمعلّم والمحرك والتوليد. قياسات الأداء والتنبيهات توجد ضمن قسم المحرك بدلاً من مزاحمة رأس كل صفحة.

## الحسابات والطلبات

تظهر الحسابات في جدول على الكمبيوتر، ويتحول إلى بطاقات ذات عناوين حقول على الهاتف. البحث بالبريد أو اسم اللاعب يرسل إلى الخادم ليشمل جميع الحسابات، مع حجم صفحة 25 أو 50 أو 100. يعرض كل صف الصلاحية والحالة والخطة وانتهاءها وعدد المباريات وزر الإدارة. تعرض الطلبات الحالة الفعلية والمبلغ وتاريخ التسجيل، ويمكن ترشيحها بحالة الدفع على الخادم. سجل التغييرات يعرض التفاصيل عند الطلب بدلاً من فتح JSON لكل إجراء دفعة واحدة.

## القوائم والنماذج

- اضغط قائمة أو اكتب للبحث، واستعمل الأسهم وHome وEnd للتنقل، وEnter للاختيار. Escape يلغي البحث دون إغلاق نافذة التعديل. Tab يغادر القائمة مع الاحتفاظ بالقيمة المثبتة؛ لا يثبت نتيجة بحث لم تخترها.
- تستمر عناصر `select` الأصلية كمصدر لقيم النماذج والتحقق منها. العناصر المعطلة لا تصبح قابلة للاختيار. أسماء الخيارات تعامل كنص، ولا تتحول إلى HTML.
- ترتيب بدائل المعلّم أصبح ثلاث قوائم مرتبة مع خيار «بدون بديل». يمنع الحفظ تكرار المزود الأساسي أو البدائل. أسماء Groq Cloud وxAI Grok مميزة بوضوح. يبقى تحقق الخادم وصلاحياته والتأكيد بكلمة المرور نافذاً.
- يظهر تنبيه بالتغييرات غير المحفوظة قبل تحديث القسم أو مغادرته أو إغلاق نافذة التعديل. توجد أزرار حفظ وإلغاء واضحة؛ عند تعديل نموذجين للمستخدم لا يغلق حفظ أحدهما نافذة فيها تعديل آخر غير محفوظ.
- تبديل اللغة يحدّث العناوين والخيارات دون إعادة إنشاء النماذج أو فقدان النصوص والمفاتيح المكتوبة. لا تُخزن القيم السرية في localStorage. الخادم يعيد مؤشرات حفظ المفاتيح، ويظل حقل المفتاح فارغاً للاحتفاظ بالمفتاح السابق.
- عند تعذر تحميل قسم يظهر خطأ وزر إعادة المحاولة. استجابة قديمة أو خطأ من طلب سابق لا يستبدلان القسم الذي انتقلت إليه. لا يوجد تحديث دوري مفروض يعيد رسم النماذج أثناء الكتابة.

لا تغيّر هذه الواجهة البيانات أو بوابات الدفع تلقائياً، ولا تتطلب migration. النماذج تحافظ على واجهات API الحالية وCSRF وتأكيد الإجراءات الحساسة. خطوات حساب التاجر وGoogle Play ما زالت موثقة في [دليل الإدارة](ADMIN_CONTROL.md).

## الاختبارات والنشر

`npm test` يتضمن اختبار القوائم: قيم FormData، البحث دون تغيير الاختيار، لوحة المفاتيح، التحقق من الحقول المطلوبة، الخيارات المعطلة، النص غير الموثوق، وتبديل اللغة. اختبارات DOM السابقة تغطي الأقسام الأحد عشر وحقول المفاتيح وGoogle Play.

`npx playwright test tests/browser/admin.spec.cjs` يختبر التنقل والبحث الحقيقي، إنشاء خطة في قاعدة الاختبار المؤقتة، القوائم داخل نوافذ التعديل، عدم إرسال مزودي AI عند تكرار البدائل، حفظ المدخلات عند تبديل اللغة، رفض فقدانها، أخطاء التحميل وإعادة المحاولة والاستجابات المتأخرة. يعمل على أربعة أحجام: 320 و390 و768 و1280. لا يضع خططاً أو مفاتيح اختبار في قاعدة النشر.

ترقية الخادم تستخدم صورة إصدار محددة المصدر، وفحصاً معزولاً، ونسخة احتياطية خاصة مشفرة مع تجربة استعادة. أرشيفات المباريات العامة والنسخ السابقة منها تظل محفوظة بصورة منفصلة؛ لا حاجة إلى إعادة استيرادها لترقية الواجهة. حدّث الصفحة بعد النشر حتى تُحمّل ملفات JavaScript وCSS الجديدة معاً.

## البنرات والإعلانات

تتوفر خريطة للمواضع الأربعة، ومحرر بوستر ورابط أو Google AdSense، وتفعيل وإخفاء مستقلان وجدولة واستهداف ومعاينة فعلية دون احتساب. إعدادات النظام تتحكم في كل موضع وعتبة الشاشات الكبيرة والتكرار. راجع [دليل الإعلانات ومتطلبات Google واختباراته](ADVERTISING.md). هذا التحديث يضيف ترحيلاً إضافياً لجداول الإعلانات، بينما تحسين واجهة الإدارة السابق لم يتطلب ترحيلاً.
