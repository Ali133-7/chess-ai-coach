## الأدلة الآلية

- 27 اختبار Python للإعلانات، إضافة إلى فحوص الإدارة والأمان والتكامل السابقة. الإجمالي المتوقع في CI لهذا التحديث: **352 اختبار Python و18 مجموعة DOM**؛ نتيجة التشغيل الفعلي في GitHub Actions هي المرجع النهائي.
- اختبارات المتصفح العامة: **76 حالة** عبر أربعة أحجام، منها نصوص عربية وإنجليزية بأقصى أطوال الحقول، مع فحص عرض 320/390/768/1280/1799/1800/1920/2200 وعدم تجاوز حواف الشاشة أو ارتفاع البنر المخصص 760px.
- اختبارات HTTPS المنفصلة: **24 حالة** عبر أربعة أحجام. تستعمل شهادة مؤقتة ونطاق example محلياً وسكربت Google مُعترضاً بالكامل. تختبر nonce بعد الدخول، تنفيذ eval اللازم للتوافق، منع حقن HTML، loaded/blocked/unfilled/pending، وحدود الطلبات والأعمدة وعدم التكرار في الخلفية. لا تثبت هذه المحاكاة قبول AdSense أو تسليم إعلان حقيقي.
- `scripts/advertising_load_test.py`: 1000 حملة و20000 سجل مشاهدة اصطناعي، ودفعات 10/25/50 مستخدماً. كل معاملة تحتوي اختياراً واستطلاعاً وإقرار مشاهدة. التشغيل المحلي أعاد **255 طلباً دون أخطاء**، مع سلامة قاعدة البيانات والمفاتيح الأجنبية. وسيط زمن المعاملة ذات الطلبات الثلاثة كان نحو 354/922/1877ms، وp95 نحو 832/1588/3269ms، على جهاز الاختبار المحلي. هذه قياسات ASGI مؤقتة داخل العملية، وليست وعداً بسعة خادم الإنتاج أو زمن الإنترنت.

يشغل CI هذه الفحوص وفحص الاعتماديات، ويحفظ تقارير المتصفح واختبار الضغط. لا يضع مستخدمي الاختبار أو صورهم أو مشاهداتهم في قاعدة التشغيل.

## المتبقي قبل تشغيل إعلانات حقيقية للعامة

1. نطاق عام مع HTTPS وضبط الأصل وHost والبروكسي والكوكيز الآمنة، ومراقبة الموارد وحدود الاتصال والطلبات على البروكسي. لا يكفي نفق localhost لإثبات التشغيل العام.
2. حساب ناشر فعلي، وملكية النطاق، وحالة Ready في AdSense، ووحدات تابعة للحساب. يمكن نشر ads.txt بحفظ معرّف الناشر قبل تفعيل الوحدات.
3. نشر سياسة الخصوصية وإعداد CMP المعتمدة حيث تنطبق متطلبات Google. مربع الجاهزية إقرار مدير، وليس تثبيت CMP أو إثباتاً للموافقة. ولأن المحتوى الحالي محمي بتسجيل الدخول، راجع إعداد وصول زاحف AdSense ومراجعة المحتوى المحمي مع حساب الناشر؛ لا تكشف حسابات المستخدمين للزاحف.
4. اختبار تسليم فعلي على النطاق المعتمد مع أدوات تشخيص المتصفح وAdSense، وفحص إعدادات Auto ads وتحسين حجم الوحدات في حساب Google كي لا تضيف مواضع أو تمدداً خارج توزيع المنصة. لا تنقر الإعلانات للتحقق.

لا يمكن لفحص آلي أن يضمن غياب جميع الأخطاء المستقبلية أو اعتماد الحساب لدى Google. تؤكد هذه المراجعة المعالجات والحالات المختبرة وحدود الموارد المذكورة؛ الخدمات والسياسات الخارجية تحتاج متابعة عند تشغيلها وتحديثها.
