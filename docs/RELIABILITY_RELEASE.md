# تطوير الاعتمادية وجودة التعليم

هذه المرحلة تنفذ ستة محاور فوق البنية الحالية. الترحيلات إضافية؛ لا تحذف حسابات أو تحليلات أو تقدم التدريب. تحديث المستودع لا يغيّر التشغيل المنشور تلقائياً. SMTP والنسخ خارج السيرفر والنشر من GitHub تحتاج إعدادات حقيقية يملكها المشغّل؛ لا تُرفع مفاتيح أو قواعد خاصة إلى Git.

| المحور | التنفيذ والاستخدام |
|---|---|
| المراقبة والتحمل | سجل دائم وتنبيهات في الإدارة ← Performance، وأداتا `check_operations.py` و`load_test.py` |
| جودة المعلّم | 64 حالة أصلية ثنائية اللغة وفحوص القانون والنية والتكرار ومقارنة المزودين عبر `evaluate_teacher.py` |
| نقاط الضعف | مركز المعرفة ← ما الذي أحتاج إلى تحسينه؟ أمثلة وأرقام واتجاه زمني وتمارين مناسبة |
| مصدر التقييم | مراجعة المباراة ← مصدر التقييم وبحث إضافي؛ نتائج منفصلة تحافظ على التحليل الأصلي |
| أمان الحساب | إعداداتي ← حماية حسابي وأجهزتي؛ MFA ورموز استرداد وجلسات وتأكيد البريد واستعادة كلمة المرور |
| النشر والاستعادة | صورة ثابتة بالبصمة، ترحيل معزول، ترقية مشتركة وتراجع يراعي MFA ونسخ مشفر؛ [دليل التشغيل الآلي](RELEASE_AUTOMATION.md) |

## 1. المراقبة واختبار التحمل

تبقى `/api/analysis/metrics` متوافقة: آخر 128 عينة في العملية لكل route. السجل الجديد في `telemetry.sqlite3` بجوار `STUDIO_DB`، أو في `STUDIO_TELEMETRY_DB`، منفصل عن قاعدة المستخدمين. يحتفظ بتجميع الدقائق 30 يوماً.

- `GET /api/operations/metrics?hours=24` للمدير، بنطاق 1–720 ساعة.
- `GET /api/operations/alerts` للمدير؛ ويمكن تشغيل `python scripts/check_operations.py --hours 1` من نظام المراقبة. exit code 1 يعني وجود تنبيه.
- `X-Request-ID` معرف يولده الخادم، ولا يثق بقيمة يرسلها العميل.
- العد والمتوسط دقيقان للعينات المحتفظ بها. p95 التاريخي **حد أعلى** من histogram بفواصل 10/50/100/250/500/1000/5000ms؛ `null` يعني أن الرتبة فوق 5000. لا نساويه بـp95 الدقيق لاختبار الحمل.
- المخزن المؤقت محدود بـ4096 مفتاح، ويفرّغ كل خمس ثوانٍ وعند الإغلاق المنظم وقراءة التقرير. الانهيار قد يفقد آخر دفعة؛ عداد العينات التي تعذر حفظها معلن ولا يعطل طلب المستخدم.
- تحفظ القياسات مدة محاولات AI وحالتها والتوكنات إذا أبلغ عنها المزود، دون أسئلة أو إجابات أو بريد أو معرف مستخدم أو query strings أو مفاتيح. بيانات cgroup تعرض عند توفرها، وإلا `null`؛ عدد معالجات المضيف لا يساوي حصة الحاوية.

التنبيهات: 5xx فوق 5% بعد 20 عينة على الأقل، وp95 فوق `STUDIO_HTTP_P95_ALERT_MS=1000` بعد 20 عينة للصف، وطلب تحليل أقدم من `STUDIO_QUEUE_ALERT_SECONDS=900`، ومباريات بحالة خطأ. فشل مزود فوق 20% يحتاج خمس محاولات على الأقل. وجهة تنبيه خارجية لا تُفعّل تلقائياً؛ اربط الأمر/الواجهة بأداة المراقبة المعتمدة.

```bash
python scripts/load_test.py --levels 10,25,50 --seconds 30 --engine --output mixed-load.json
```

الاختبار ينشئ خادماً على loopback وقواعد مؤقتة و50 حساب fixture، ويرفض منفذاً مشغولاً ويتحقق من هوية الخادم قبل استخدام الجلسات. الألعاب مسارات قانونية مولدة للحمل، وليست مباريات تاريخية. لا تُخترع تقييمات؛ `--engine` يشغل Stockfish الحقيقي بخيط وميزانية محدودين. المزامنة الخارجية وSMTP والتحصيل وAI المدفوع معطلة.

يبدأ القياس بعد تجهيز العملاء وتسخين الاتصالات: 30ms تفكير، وست قراءات محمية وتحديث تفضيل واحد كل سبعة طلبات. p95 يستخدم nearest rank. يمكن ضبط `--max-p95-ms` و`--max-error-rate`. نجاح التقرير بدون حد p95 يعني اجتياز حد الأخطاء فقط، وليس اعتماد سعة.

قياس محلي أثناء التطوير، خمس ثوانٍ لكل مستوى، Python 3.12.10 ومضيف يعرض 16 معالجاً منطقياً، مع Stockfish في الخلفية:

| مستخدم افتراضي | طلبات | أخطاء | p95 ms |
|---:|---:|---:|---:|
| 10 | 556 | 0 | 116.12 |
| 25 | 401 | 0 | 481.62 |
| 50 | 326 | 0 | 1465.52 |

هذه نتائج جهاز التطوير، وليست قياساً للسيرفر أو ضماناً لخمسين مستخدماً حقيقياً. workflow `Measure mixed load` يتيح إعادة قياس 30 ثانية لكل مستوى؛ وCI يجري تجربة قصيرة للتحقق من الأداة.

## 2. مختبر المعلّم

`evaluation_cases.json` يضم 16 موضوعاً، وصياغتين لكل لغة: 64 حالة. الأسئلة ووسوم المفاهيم مادة أصلية، وليست 64 مباراة أو حقيقة مستقلة. قانونية الوضعيات والنية تُراجع دون فتح قاعدة المستخدم أو استدعاء مزود.

```bash
python scripts/evaluate_teacher.py
python scripts/evaluate_teacher.py --responses /private/answers.jsonl --output /private/evaluation.json
```

كل سطر إجابة يتضمن `case_id` و`answer` وفق `TutorAnswer`، ويمكن إضافة provider/model/latency_ms/input_tokens/output_tokens. يجمع التقرير صلاحية البنية، وفحص التناقض المحدود، وتغطية مجموعات الكلمات، وتشابه النصوص ≥0.90 بين موضوعات مختلفة باللغة نفسها، والزمن والتوكنات لكل مزود ونموذج.

تغطية الكلمات والتشابه **مؤشرات للمراجعة** وليسا حكماً دلالياً أو اعتماداً تربوياً. `human_review` يبقى `null`. فحص الكش/الأسر/المات يخص عبارات صريحة محددة، ولا يثبت النص كله. corpus لا يقدم PV محسوباً؛ لا يقبل معرفات سيناريوهات مخترعة ولا يدعي اختبار جودة بحث محرك عميق.

المقارنة الحية اختيار صريح يستهلك حصة المزود، بحد خمس حالات افتراضياً و64 كحد أقصى لكل مزود، ودون fallback صامت:

```bash
python scripts/evaluate_teacher.py --live groq --live openai --max-cases 5 --output /private/provider-comparison.json
```

لم تُنفّذ مقارنة مدفوعة ضمن اختبارات الإصدار. الكلفة المالية تبقى `null` دون أسعار حقيقية. `--pricing-file` يقبل provider ثم model، مع `currency: USD` و`input_per_million` و`output_per_million` و`as_of`. لا توجد أسعار تجارية مختلقة مرفقة. النتيجة تقدير من توكنات المزود وأسعار المشغّل وليست فاتورة.

## 3. تشخيص اللاعب

```text
GET  /api/training/diagnostics
POST /api/training/diagnostics/refresh  {"limit":20}
GET  /api/training/diagnostics/exercises?skill=fork
```

كلها مملوكة للحساب. التحديث اليدوي لأحدث 20 مباراة، بحد ست مرات/ساعة. العامل يحدث ملاحظات اللعبة بعد اكتمالها. البصمة تشمل PGN والاسم المرتبط وصفوف التحليل ونسخة الخوارزمية؛ التكرار لا يكرر الملاحظات. حذف اللعبة/المستخدم يحذف الأدلة المرتبطة بـFK. لا يُعلّم تمرين بأنه منجز ولا يُكشف حله بمجرد اقتراحه.

يتحدد اللون من الاسم المرتبط ودور الرقعة الفعلي، بما فيه FEN يبدأ بالأسود. الاسم العام لا يثبت ملكية حساب Chess.com. النسبة = أخطاء مرصودة ÷ نقلات محللة مؤهلة؛ النقلات غير المصنفة لا تدخل المقام. فئات المراحل تستخدم مقام المرحلة فقط، وحدود المراحل موروثة وتقريبية.

القطعة غير المحمية تحتاج خسارة محفوظة ≥100cp وأخذاً قانونياً وغياب مدافع من لونها. الشوكة تحتاج رداً فعلياً قانونياً يهدد هدفين من الملك/القطع، مع خطأ محفوظ؛ هذا لا يثبت ربح مادة إجبارياً. قد تتداخل الوسوم. الأمثلة تفتح المباراة والنقلة مع دليل التصنيف.

الاتجاه يقارن النصف الأقدم بالنصف الأحدث من الألعاب المعالجة زمنياً، بعد عشر مباريات و30 نقلة مؤهلة في كل نصف على الأقل. فرق النسبة بالنقاط المئوية وصف للعينة، وليس دلالة إحصائية أو إثباتاً سببياً للتحسن أو تقديراً لـElo.

## 4. مصدر التقييم والبحث الإضافي

الحسابات الجديدة تحفظ `analysis_meta`: بصمة المحرك وهويته إن أعلنها، نسخة الخوارزمية، الوقت وMultiPV والخيوط والذاكرة، العمق المتاح والمدة والتوقيت. تحفظ الخطوط nodes/seldepth/engine_time إن أعادها UCI. الوضعية المنتهية تُعرّف بنتيجة قواعد، والمجهول يبقى `null`.

لا تُضاف معلومات متخيلة للـcheckpoints القديمة. إصابة الكاش تحتفظ بتاريخ حسابها الأصلي. وقت الطلب ليس تاريخ إعادة حساب وهمياً.

```text
GET  /api/games/{gid}/positions/{ply}/evidence
POST /api/games/{gid}/positions/{ply}/reanalyze  {"seconds":30,"multipv":3}
GET  /api/analysis/experiments/{id}
```

`ply` يبدأ من 1؛ البحث على الوضعية قبل النقلة مع تاريخها القانوني. يشترط اكتمال المباراة وتحليلها وملكيتها وميزة review وCSRF. الميزانيات 10/30/60/120 ثانية وMultiPV من 1 إلى 3؛ طلبان معلقان للحساب، و20 عالمياً، و20 طلباً يومياً للحساب.

البحث محجوز برمز وlease ويستخدم الكاش القانوني نفسه. يخدم العامل دفعة التحليل المعتادة أيضاً، ويحفظ التجربة منفصلة دون استبدال `moves` أو `position_scans`. الوقت الأكبر لا يضمن عمقاً أكبر أو صحة قطعية. قد تعاد نتيجة موجودة متوافقة. المقارنة من منظور الأبيض بوحدة centipawn؛ الفرق بين بحثين ليس برهاناً. إغلاق النافذة يوقف polling، وقد يكمل البحث الخلفي.

## 5. الحسابات والبريد

الحسابات القديمة تحتفظ بكلمات المرور والأدوار، ولا تُعلّم مؤكدة البريد تلقائياً. الجداول الجديدة منفصلة عن users/sessions. قائمة الجلسات تعرض معرفاً عاماً لا رمز الدخول أو بصمته الكاملة، وتُعلن غياب تاريخ إنشاء جلسة قديمة.

MFA وفق RFC 6238: سر عشوائي 160-bit في ملف خاص، وHMAC-SHA1، ورمز 6 أرقام كل 30 ثانية ونافذة ±خطوة. كلمة المرور تسبق تحدياً مدته خمس دقائق وخمس محاولات، مربوطاً بإصدارها والسر، ويُستهلك ذرياً. لا تصدر جلسة كاملة قبل العامل الثاني، ولا يقبل رمز TOTP للخطوة نفسها مرتين. يلزم ضبط الساعة.

التفعيل يحتاج كلمة المرور ورمز التطبيق، وينهي الجلسات الأخرى. رموز الاسترداد العشرة محفوظة كبصمات وتظهر مرة واحدة وتُستخدم مرة واحدة. يمكن تدويرها بكلمة المرور وعامل صالح؛ السابقة تُبطل. التعطيل يحتاج العاملين أيضاً. أسرار الإعداد المستبدلة والمعطلة تُحذف بعد المعاملة. `STUDIO_REQUIRE_ADMIN_MFA=true` سياسة اختيارية؛ فعّلها **بعد** تسجيل كل المديرين وحفظ رموزهم.

روابط البريد في fragment، يُزال من شريط العنوان عند فتح الواجهة، وتحتاج تأكيداً وPOST؛ ماسح البريد لا يستهلكها بمجرد GET. الرموز عالية العشوائية، محفوظة كبصمات، محدودة الصلاحية، مرة واحدة، ومربوطة بإصدار كلمة المرور. الاستعادة تنهي كل الجلسات والتحديات **وتُبقي MFA مفعلاً**. تأكيد البريد لا يثبت ملكية Chess.com.

### تهيئة SMTP

```dotenv
STUDIO_BASE_URL=https://your-domain.example
STUDIO_COOKIE_SECURE=true
STUDIO_SMTP_HOST=your-smtp-host.example
STUDIO_SMTP_PORT=587
STUDIO_SMTP_MODE=starttls
STUDIO_SMTP_FROM=coach@your-domain.example
STUDIO_SMTP_USERNAME=your-smtp-user
STUDIO_SMTP_PASSWORD_FILE=/studio-data/smtp-password
```

القيم أمثلة يجب استبدالها. كلمة المرور في ملف خاص بصلاحية 600 خارج Git. بديل `ssl` يستخدم TLS مباشرة والمنفذ 465 افتراضياً؛ لا يوجد وضع مصادقة بنقل مكشوف. يلزم origin حقيقي بـHTTPS للبريد. ثم شغّل العامل بصورة الإصدار نفسها:

```bash
docker compose --profile mail up -d --no-deps mail-worker
```

لا إرسال قبل اكتمال الإعداد. payload الرابط في ملف خاص يُحذف بعد الإرسال أو الفشل النهائي/الانتهاء. حتى خمس محاولات بتأخير، وأخطاء عامة دون نص SMTP أو أسراره. التعطل بعد الإرسال وقبل الحفظ قد يكرر الرسالة نفسها؛ لا ندعي exactly-once. رد الاستعادة عام للحساب المعروف وغير المعروف، مع حدود IP والبريد.

دون نطاق HTTPS أو SMTP حقيقي تبقى خدمة البريد غير مفعلة بوضوح. MFA والجلسات تعملان دون بريد. مسارات التسليم تُختبر بمزود معزول؛ عند تفعيل خدمة حقيقية اختبر وصول رسائلها وتحقق النطاق.

## 6. الترحيل والتحقق

الجداول الإضافية: `analysis_experiments`، و`player_skill_games` و`player_skill_observations`، و`account_security` و`account_session_info` و`account_challenges` و`account_recovery_codes` و`account_email_tokens` و`account_mail_outbox`. جدول `telemetry_buckets` في قاعدة منفصلة. مخطط SQL خالٍ من الصفوف؛ لقطة المعرفة العامة وبصماتها لا تستبدل بقاعدة تشغيل.

```bash
PYTHONPATH=.:tests python -m unittest test_account_security test_reliability_analysis test_encrypted_backup test_release_promotion -q
python scripts/evaluate_teacher.py
npm test
npx playwright install --with-deps chromium
npm run test:e2e
python -m scripts.refresh_database_schema
```

على PowerShell اضبط `$env:PYTHONPATH='.;tests'`. يمكن تحديد `CHESS_E2E_PYTHON` واستخدام Chrome المثبت عبر `CHESS_E2E_CHANNEL=chrome`. حسابات المتصفح معزولة؛ سكريبت fixture وحده يزيد ميزانية تسجيل الدخول المتكرر، ولم تُرفع حدود حماية التطبيق الحقيقي. الحالات تشمل MFA ورمز الاسترداد وإنهاء جلسة جهاز آخر واللغة والرقعة والطابور والبحث الإضافي على أربعة أحجام.

المصادر: [RFC 6238](https://www.rfc-editor.org/rfc/rfc6238)، و[OWASP Forgot Password](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)، و[SQLite Online Backup](https://www.sqlite.org/backup.html)، و[GitHub Container Registry](https://docs.github.com/en/actions/tutorials/publish-packages/publish-docker-images). الانتقال إلى PostgreSQL يرتبط بقياسات تزامن الكتابة أو توزيع الخدمة، وليس عدد المباريات وحده.
